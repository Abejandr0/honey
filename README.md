# Pulso 💞

Demo interactiva de una app para smartwatch pensada para parejas. No es un chat: es comunicación rápida, discreta y emocional.

## Funciones simuladas
- **Cariño:** toque, abrazo y beso con vibración en el otro reloj.
- **Mensajes rápidos:** frases predeterminadas, traducidas según el idioma de quien las recibe.
- **Ánimo:** comparte un emoji de estado.
- **Ubicación compartida:** mapa simulado con distancia y permiso por persona.
- **Ajustes por reloj:** idioma (ES/EN), modo claro/oscuro, 5 temas de color, No molestar y vibración.
- **Modo presentación:** recorrido automático con subtítulos.

## Cómo ejecutarla
Abre `index.html` en el navegador. No necesita instalación ni servidor.

## Publicar en GitHub Pages
1. Sube los archivos a un repositorio.
2. Settings → Pages → Branch `main` → carpeta `/ (root)` → Save.
3. Tu demo quedará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Estructura
- `index.html`: estructura de la página
- `styles.css`: estilos y temas
- `app.js`: estado, lógica y modo presentación
